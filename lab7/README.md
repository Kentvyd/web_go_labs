# Лабораторная работа 7

## Задания
1. Создание TCP-сервера: слушает порт, принимает соединения, выводит сообщения клиента и отправляет подтверждение.
2. Реализация TCP-клиента: подключается к серверу, отправляет сообщение пользователя и ждёт ответ.
3. Асинхронная обработка клиентов: горутина на каждое соединение и graceful shutdown.
4. Создание HTTP-сервера: GET /hello и POST /data (JSON).
5. Маршрутизация и middleware: несколько маршрутов и логирование метода, URL и времени выполнения.
6. Веб-сокеты: сервер чата для нескольких клиентов.

## Структура
Каждое задание — отдельная программа в своей папке (task1...task6).

## Запуск
Из папки lab7 выполнить (серверы останавливаются по Ctrl+C):
go run ./task1   (TCP-сервер, порт 9000)
go run ./task2   (TCP-клиент; сервер из task1 или task3 должен быть запущен)
go run ./task3   (TCP-сервер с горутинами и graceful shutdown, порт 9000)
go run ./task4   (HTTP-сервер, порт 8080)
go run ./task5   (HTTP-сервер с middleware, порт 8080)
go run ./task6   (чат на веб-сокетах, порт 8080)

Серверы task1/task3 используют один порт 9000, а task4/task5/task6 — порт 8080,
поэтому запускать их нужно по очереди, остановив предыдущий.

## Зависимость для task6
Для веб-сокетов нужен внешний пакет. Один раз выполнить в папке lab7:
go get github.com/gorilla/websocket
(команда добавит зависимость в go.mod и создаст go.sum — их нужно закоммитить).
