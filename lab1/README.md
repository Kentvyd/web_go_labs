# Лабораторная работа 1

## Задания
1. Вывести текущее время и дату
2. Создать переменные различных типов (int, float64, string, bool)
3. Использовать краткую форму объявления переменных
4. Арифметические операции с двумя целыми числами
5. Функция для вычисления суммы и разности двух чисел с плавающей запятой
6. Вычисление среднего значения трёх чисел

## Структура
Каждое задание — отдельная программа в своей папке (task1...task6).

## Запуск
Из папки lab1 выполнить:
go run ./task1
go run ./task2
go run ./task3
go run ./task4
go run ./task5
go run ./task6
